# Telco Customer Churn & Retention Analytics

An end-to-end data analytics and machine learning project designed to predict, analyze, and mitigate customer churn for telecommunications companies. This project combines **Python (Scikit-Learn)** for predictive modeling, **MySQL** for relational data engineering, and **Power BI** for executive business intelligence storytelling.

---

## 📊 Executive Summary
Customer churn is one of the most critical metrics for subscription-based businesses. This project analyzes **7,043 customer records**, engineering an automated machine learning classification pipeline and a real-time executive Power BI dashboard to uncover high-risk subscriber segments, quantify revenue loss, and guide retention strategies.

---

## 🛠️ Tech Stack & Tools
* **Programming Languages:** Python (Pandas, NumPy, Scikit-Learn)
* **Databases & Querying:** MySQL Workbench, Relational Schema Design
* **Business Intelligence & Visualization:** Power BI Desktop (DAX Measures, Executive UI/UX Design)
* **Version Control:** Git & GitHub
